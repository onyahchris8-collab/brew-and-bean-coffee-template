# ☕ brew&bean: Coffee Shop Website Template

A modern, dark-themed coffee shop website template built with HTML, CSS and JavaScript. Free to use, customize and upgrade.

## ✨ Features
- Elegant dark design with warm coffee tones
- Hero section, menu, story and visit-us sections
- Shopping bag counter in the navbar
- Order and visit buttons linked to Starbucks for a realistic, usable feel
- Clean, easy-to-edit code

## 🛠 Built With
- `index.html`: page structure
- `style.css`: styling and layout
- `script.js`: interactions and functionality

## 🚀 How to Use
1. Clone the repo: `git clone https://github.com/your-username/brew-and-bean-coffee-template.git`
2. Open `index.html` in your browser
3. Edit the text, colors and images to make it yours

## 🔧 Ideas to Upgrade
- Connect it to your own ordering system
- Add a real cart and checkout
- Swap in your own brand, photos and menu
